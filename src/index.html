词格酱 · 中文歌词写作台

按作曲给出的词格摆好空格子，你只管往里填字。

导入格式

纯文本 .txt，段落标记用中括号或直接写 Verse/Chorus，X 表示一个字，空格表示停顿分组，空行也可分段：

[Verse]
XXXX XXX
XXX XXXX
XX XXXXX

[Chorus]
XXXXX XXX
XXXX XXXX

也支持这些写法：数字词格 4+3 或 7；○ ● □ × 等占位符；直接粘贴一段现成歌词，会自动反推词格并填入文字。

导入 MIDI（实验功能）

按旋律的音符数量自动生成词格：普通音符每个算一格，另外放三个 keyswitch 当分段标记（力度无所谓，事件存在就算数，需要跟旋律在同一条音轨/通道上，靠音高区分）：

  • C0（MIDI note 24）：分句断点——把当前这一句切成下一个停顿分组
  • C#0（MIDI note 25）：换句——结束当前句，下一个音符开始算新的一句
  • D0（MIDI note 26）：换段落——结束当前段落，下一个音符开始算新的一段

两个 keyswitch 中间要是一个音符都没有，就不会生成空分句/空句/空段落。这里的音高编号是按 Standard MIDI File 里的绝对音高算的（也就是 Studio One 的显示习惯：Middle C = C3 = 60），不是所有 DAW 都一样，导出前最好自己确认一下。导入只生成格子，字还没填。

顶部两个 MIDI 导出按钮要在同一次会话里导入过 MIDI 才能用（导入的原始数据只留在内存里，刷新页面要重新导入）：

  • 导出纯净 MIDI：去掉三个 keyswitch，其余音符、音轨、meta 信息原样保留。
  • 导出带歌词 MIDI：导出前会逐句、逐分句核对一遍当前词格是不是还跟导入时的 MIDI 对得上——导入之后如果手动加减过格子/句/段，这里会精确报出是第几段第几句对不上，直接拦住不导出，防止歌词跟音符错位。核对通过才会去掉 keyswitch，并在每个演唱音符上插入一个歌词事件（Standard MIDI 的 Lyric meta event，Synthesizer V 等支持 MIDI 歌词的软件能读）。没填的格子会导出成空歌词，不会拦你。

快捷键

  • Enter 跳到下一句（不会新建句子；想加句子用下方的「＋ 新增一句」）
  • Tab / Shift+Tab 下一句 / 上一句
  • ↑ ↓ 跨句移动，保持光标列位置
  • Ctrl/⌘ + ] / [ 在光标所在的分句里加 / 减一格
  • Ctrl/⌘ + \ 在光标处断开分句；光标已在分句边界时则合并相邻两个分句
  • Alt + ↑/↓ 上移 / 下移整句
  • Alt + ←/→ 把整句的字左移 / 右移一格（词格不动；会把字挤出词格时会拦住）。手机上没有 Alt 键，用这一行工具栏里的 ← → 两个按钮
  • 空句上按 Backspace 删除该句
  • 点左侧灰色数字（如 2/2/3）可直接改本句词格，输入 2 2 3、2/2/3 或 XX XX XXX 均可

背景

点顶部的「背景」可以换成自己的图片或纯色，也可以直接把图片拖进窗口。

  • 底色：夜间 / 稿纸两套，决定文字和格子的颜色。
  • 图片：会自动缩到合适尺寸再记住，不会拖慢程序。图片背景下可以调「蒙版浓度」和「模糊」两个滑块，把字压得清楚一些。
  • 纯色：选浅色会自动配深色字，选深色自动配浅色字。

光标与留空

点哪个格子，字就写在哪个格子——包括还没写到的空格子。比如你先想好了句尾那几个字，可以直接点到最后几格写下来，前面的格子留着慢慢填。

留空的格子在内部记作空格，不计入字数（右侧的 3/7 只数真正写了的字），导出时句尾多余的空格会自动去掉。句子中间敲空格也是同样的意思：跳过这一格。

分句（句内停顿）

词格中的空格代表一个停顿，例如 2/2/3 就是三个分句。光标落在哪个分句，下方就会出现一条橙线，此时 ＋ − 只作用于这个分句：把光标点进中间的 2，按 ＋ 得到 2/3/3，按 − 得到 2/1/3；分句只剩 1 格时再按 − 会整段去掉，变成 2/3。

日语拗音（实验功能）

打日语歌词时，きゃ しゅ ちょ 这类拗音会自动跟前一个假名拼成一格，显示为主字右下角的小字，不单占格子——这样数格子才对得上日语的音拍数。促音 っ／ッ 不算在内，仍然独立占一格，因为它数拍时本来就该自己算一整拍。

韩语谚文（如 한）本身就是一个完整字符，天然一格一个音节，不需要额外设置。

备选版本与备注

光标落进某一句，这句下面就会展开一条工具栏。

  • ＋ 存为备选：把这句现在的写法存进版本清单，然后你可以继续改写。同一句想到几种写法就存几种。
  • 点带编号的小方块即可在各版本间来回切换，高亮的那个是当前生效的版本，小 × 删掉不要的。
  • 写了新东西还没点存时，前面会多出一个「未存」方块；这时候去点别的版本，工具会先自动把这份新写法存住再切换，不会丢稿。
  • 右边的备注输入框写给自己看的提示，比如「这句想押 ang 韵」「等作曲确认」。备注不占格子，也不计入字数。
  • 有备选或备注的句子，工具栏会一直显示；其余的只在光标进入时出现。

点「导出歌词」时可以勾选是否把全部备选（同句用 / 分隔）和备注（写在句末的 （） 里）一并写进 TXT，勾选状态会被记住。「保存工程」导出的 json 始终包含全部备选和备注。

反过来，「导入词格 TXT」时如果一句末尾带着 （……），会自动拆出来当这句的备注，括号本身和里面的字都不占格子——正好跟导出的格式对上。只认贴在行尾的括号，句首或句中的括号仍然当普通标点处理。
